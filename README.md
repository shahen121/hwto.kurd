# hwto.kurd

واجهة عربية (RTL) عصرية للأفلام والمسلسلات، مبنية كـ SPA خفيفة بدون أي إطار عمل
وتستهلك فقط واجهة `https://kurdcinama.com/api/TMDBCache.aspx`.

لا يوجد مفتاح TMDB في الواجهة: كل طلبات البيانات تمر عبر `server.js` (نفس المصدر)،
ولذلك لا توجد مشاكل CORS ولا مفاتيح مكشوفة في المتصفح.

## التشغيل

```bash
node server.js          # أو: npm start
# → http://127.0.0.1:4173
```

المتطلب: Node 18+ فقط. لا يوجد `npm install` — لا توجد أي تبعيات.

```bash
PORT=8080 node server.js         # منفذ مخصّص
HOST=0.0.0.0 node server.js      # استقبال من الشبكة
```

## الفحوصات

```bash
node scripts/check.js            # بنية + صياغة + قواعد أمنية  (npm run check)
node scripts/check.js --smoke    # ما سبق + إقفال الخادم واختبار الـ proxy فعلياً
node scripts/qa.mjs              # بوابة المتصفح الكاملة          (npm run qa)
```

`scripts/qa.mjs` يفتح Chromium بلا واجهة ويتحقّق من تغطية كل المسارات،
الحالات (تحميل/خطأ/فارغ/404)، الصور المكسورة، عدم وجود تمرير أفقي على
390/768/1440px + فتح قائمة الموبايل، تاريخ المتصفح (رجوع/تقدّم) واستعادة موضع
التمرير، رابط «تخطَّ إلى المحتوى» وعدم كسره للمسار، عنوان صفحة التفاصيل، وزر
«رجوع» عند الدخول المباشر برابط، «عرض المزيد»
في مكتبة الموقع والأفلام القادمة بدون تكرار، تأخير البحث (طلب واحد لكل كتابة)،
حقن عطل في الخادم والتأكد من أن زر «إعادة المحاولة» يعمل في القائمة **وفي
الرئيسية**، خدمة الـ cache عند إعادة الزيارة، تركيز `/` على البحث، التنقل السريع،
صفحة المشاهدة (تضمين مشغّل vidcore.io المباشر بمعرّف TMDB، تشغيل الأفلام والمسلسلات)،
رؤوس الأمان وCSP وضغط gzip (HTML/CSS/JSON)، ميزانيتي زمن وحجم أول تحميل،
وصفر أخطاء في الكونسول وصفر استجابات HTTP فاشلة (404/500). أخطاء الطرف الثالث
داخل إطار المشغّل المضمّن تُعدَّ منفصلة ولا تُحتسب ضد التطبيق. يتطلّب `playwright-core` وثنائي Chromium، والخادم يعمل على `BASE_URL` الافتراضي.

## الأداء والأمان

- **ضغط gzip** لكل نص (HTML/CSS/JS/JSON/SVG) بحدٍّ أدنى 1KB وعندما يقلّص فعلاً:
  `index.html` ‏1522 ← 769 بايت، `components.css` ‏14266 ← 3353، استجابة البحث
  ‏10080 ← 4423. يُضاف `Vary: Accept-Encoding` ويُحترم ما يطلبه العميل.
- **رؤوس الأمان** على كل الردود: `X-Content-Type-Options: nosniff`,
  `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`,
  `Permissions-Policy` مقيّد.
- **CSP** على صفحة HTML فقط: مصدر واحد للسكربتات، الاتصال محصور في `self`
  (كل البيانات تمر عبر البروكسي)، الصور فقط من `image.tmdb.org` و`kurdcinama.com`،
  والإطار `frame-src` يسمح بـ `self` و`https://vidcore.io` لشاشة المشاهدة.
  لتشغيلها دون حجب أثناء التطوير: `CSP_REPORT_ONLY=1 node server.js`.
- **ميزانية القياس** ضمن QA: أول محتوى خلال ثانية واحدة، ‏55KB من أصول الموقع
  في ‏21 طلباً.

الـ check يتحقّق من:

- صياغة كل ملفات JS وأن كل `import` نسبي يحلّ فعلاً.
- كل مراجع `index.html` (CSS/JS/favicon) موجودة.
- `fetch()` لا يُستدعى إلا داخل `public/js/api.js` (طبقة الخدمة الوحيدة).
- لا يوجد أي مفتاح API أو توكن في أي ملف.
- كل `api.*()` تُستدعى من الواجهة مُصدَّرة فعلاً، وكل `action=` موثّق في ترويسة `api.js`.

## المسارات

| المسار | الشاشة |
|---|---|
| `#/` | الرئيسية: هيرو + إحصاءات + أربعة صفوف + زر مشاهدة فوري |
| `#/trending/movie` · `#/trending/tv` | الرائجة (فلترة محلية — الخادم يتجاهل `type`) |
| `#/upcoming` | الأفلام القادمة + زر «عرض المزيد» |
| `#/toprated/movie` · `#/toprated/tv` | الأعلى تقييماً (مع إصلاح معرّفات الخادم) |
| `#/site` · `#/site/movie` · `#/site/tv` | مكتبة الموقع + تحميل تدريجي حتى 100 |
| `#/search?q=..&type=..` | بحث فوري بتأخير 400ms وفلاتر نوع |
| `#/movie/:id` · `#/tv/:id` | صفحة التفاصيل + «قد يعجبك أيضاً» + «شاهد الآن» |
| `#/watch/movie/:id?title=..` · `#/watch/tv/:id?title=&season=&episode=` | شاشة المشاهدة (مشغّل vidcore.io المباشر) |

## المشاهدة والمصادر

تعتمد المشاهدة على مشغّل `vidcore.io` الذي يقبل معرّف TMDB ID مباشرة:

- زر **«شاهد الآن»** ظاهر ومميز في الواجهة (في الهيرو وفي صفحة التفاصيل)، ويوجّه مباشرة إلى `#/watch/movie/{id}` أو `#/watch/tv/{id}`.
- يتم تضمين المشغّل مباشرة داخل `iframe` في شاشة المشاهدة:
  - الأفلام: `https://vidcore.io/movie/{tmdb_id}`
  - المسلسلات: `https://vidcore.io/tv/{tmdb_id}/{season}/{episode}`
- لا يحتاج المشغّل إلى بروكسي وسيط، و`frame-src` في الـ CSP مضبوط حصرياً للسماح بـ `https://vidcore.io`.
- الإطار محمي بخاصية `sandbox` لمنع الإعلانات المنبثقة، وتوجيه الصفحة الرئيسية، والروابط الخارجية (`sandbox="allow-scripts allow-same-origin allow-forms allow-presentation"`).

## سلوك الـ API (موثّق ومختبر، مكتوب بالكامل في ترويسة `api.js`)

| Endpoint | الحقيقة |
|---|---|
| `action=trending&type=` | **`type` متجاهَل** — نفس القائمة المختلطة (9 عناصر كحدّ أقصى). الفلترة تتم في المتصفح. |
| `action=upcoming&limit=` | أفلام فقط، 20 افتراضياً، **سقف صلب 40**، لا يقبل `type`. |
| `action=toprated&type=movie` | **خطأ في الخادم**: `id` لا يطابق العنوان (`id=11` لـ The Shawshank Redemption الحقيقي 278). |
| `action=toprated&type=tv` | **خطأ في الخادم**: `title` و`release_date` فارغتان. |
| الإصلاح المستخدم | جلب `action=toprated&limit=100` (20 فيلم + 9 مسلسل، معرّفات صحيحة) والانضمام على `local_id` + `media_type`. |
| `action=search&q=&type=` | `type` مُحترم، لا يوجد `limit`، 20/نوع كحدّ أقصى. |
| `action=mycontent&limit=` | `limit` **لكل نوع** (بدون `type` يرجع ضعفه)، و`poster_path` كثيراً فارغ → يُستخدم `db_photo`. |
| `action=stats` | `{movies,tv_shows,trending,upcoming,top_rated,oldest_cache,newest_cache}` |
| `action=movie&id=` | **لا يوجد حقل بلد**، و`genre_ids` نص مفصول بفواصل. اللغة/البلد/النوع تُترجم جداول محلية في `config.js`. |
| `action=tv&id=` | `origin_country` قد يكون مصفوفة. |
| معرّف غير معروف | يستجيب **HTTP 200** مع `{"error":"..."}` — لازم فحص الحقل `error` (وليس كود الحالة). |

معظم عناصر `mycontent` غير موجودة في كاش التفاصيل، لذلك صفحة التفاصيل تسقط تلقائياً
على العنصر المحفوظ من القائمة عبر `store.js` وتعرض تنبيهاً صريحاً عند نقص بيانات.

## قرارات تقنية

- **SPA بدون إطار عمل**: وحدات ES، بناء = لا شيء. حجم الصفحة الأولي صغير والتوجيه عبر `hash` حتى يعمل كل شيء من ملف محلي.
- **إلغاء الطلبات**: لكل تنقّل `AbortController`، والأجابة القديمة لا تستطيع كسر الشاشة الجديدة. الطلب المشترك (كاش `runOnce`) يبقى يعمل ويملأ الكاش بدل أن يُلغى.
- **الكاش ثلاثي الطبقات**: خادم 180 ث → `sessionStorage` 5 دقايق (30 دقيقة للتفاصيل) → منع تكرار الطلب نفسه أثناء الطيران.
- **الصور كسولة**: الرابط في `data-src` حتى يقترب العنصر من نافذة العرض (IntersectionObserver)، مع صورة بديلة عند الفشل وحالات تحميل/خطأ/فارغ في كل شاشة.
- **الوصول**: `dir="rtl"`، روابط قابلة للتركيز، `aria-*`، رابط «تخطَّ إلى المحتوى»، احترام `prefers-reduced-motion`.
